Datenschutzerklärung

PRZ Vorschau · Stand: Oktober 2026

Kurz gesagt

PRZ Vorschau erhebt, speichert und übermittelt keine personenbezogenen Daten. Die App funktioniert vollständig offline.

Welche Daten verarbeitet die App?

Die App liest ausschließlich die .prz-Dateien, die Sie im Windows-Explorer auswählen oder im Viewer öffnen, um deren Inhalt anzuzeigen. Die Dateien werden nur gelesen und niemals verändert. Die Verarbeitung findet ausschließlich auf Ihrem Computer statt.

Datenübertragung

Die App baut keine Netzwerk- oder Internetverbindungen auf. Es werden keine Daten an den Entwickler oder an Dritte übertragen. Es gibt keine Analyse-, Tracking- oder Werbefunktionen.

Lokale Fehlerprotokolle

Tritt beim Anzeigen einer Datei ein technischer Fehler auf, schreibt die App eine kurze Fehlermeldung in eine Protokolldatei auf Ihrem Computer (im Ordner %LOCALAPPDATA%Low). Diese Datei verlässt Ihren Computer nicht und kann jederzeit gelöscht werden.

Privacy Policy

PRZ Preview · October 2026

PRZ Preview does not collect, store or transmit any personal data. The app works completely offline. It only reads the .prz files you select in File Explorer or open in the viewer, and never modifies them. No network connections are made, and no data is sent to the developer or third parties. If a technical error occurs, a short error message is written to a local log file (%LOCALAPPDATA%Low) that never leaves your computer.
